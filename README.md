# Wobbulator release information

Public version information used by Wobbulator's optional update checks.
This repository contains no application source, customer files, license keys or user data.

Official website: https://sites.google.com/view/wobbulator/home

Existing customers can download current releases from https://app.lemonsqueezy.com/my-orders using the email address used for purchase.

Version information is published only after the corresponding customer downloads are available. Checking does not install software or upload projects. GitHub receives normal connection information such as an IP address; Wobbulator sends no license key, photo, project or device identifier.
