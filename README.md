# Wobbulator downloads and release information

Try the included examples free on Android and Windows. Paint, play, save your creations locally, reopen them and make copies without an account or trial countdown. Personal photos, imports, exports and backups require activation.

**[Download and install Wobbulator](https://sites.google.com/view/wobbulator/install-update)**

The official installation page links to the current APK and Windows ZIP. These are the same activation-ready apps supplied to customers. One $6.99 USD purchase through [Lemon Squeezy](https://wobbulator.lemonsqueezy.com) unlocks Android and Windows; activating keeps your saved example creations.

This repository hosts public app release downloads and the small `stable.properties` file used by optional update notifications. It does not contain application source code, license keys or user projects. GitHub's automatically generated source archives contain only these public release-information files; they are not app installers.

Existing customers can also use [Lemon Squeezy My Orders](https://app.lemonsqueezy.com/my-orders) with their purchase email. Share the official download page; keep license keys and private purchase links private.

Release information is updated after the corresponding customer downloads are available. Nothing is installed automatically. GitHub receives normal connection information such as your IP address when checking versions or downloading files; the app sends no photos, projects, license key or device identifier with update checks.

Local saves are not cloud backups. Keep the existing app and its data intact when updating. [Installation and backup guidance](https://sites.google.com/view/wobbulator/install-update).
